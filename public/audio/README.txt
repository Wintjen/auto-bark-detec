AUDIO FILES FOR DOG BARK DETECTOR

This directory is where you can place audio files that will play when a dog bark is detected.

To use a default response sound:
1. Add an MP3 file named "response.mp3" to this directory
2. The app will automatically use this file when a bark is detected

Alternatively, you can upload your own audio file through the app's interface.

Recommended audio file characteristics:
- Short duration (1-5 seconds)
- Clear sound that will get your dog's attention
- MP3 format for best browser compatibility
